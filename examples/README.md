# Examples

Worked examples a participant can follow step by step: the problem sentence to type, the
dataset link to paste, what to answer when the agents ask, and what to expect at each stage.

- [Map flood water](flood-mapping.md): Prithvi-EO-2.0 on Sen1Floods11, fetched from a
  Hugging Face link, through all seven stages.
- [Map wildfire burn scars](burn-scars.md): Prithvi-EO-2.0 on HLS satellite chips that are
  already on the studio's machine.
- [Datasets to try](datasets.md): more public datasets for Prithvi-EO, Prithvi-WxC and
  both together, each with a first message to paste.
